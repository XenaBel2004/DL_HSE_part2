# Домашнее задание 6. Исследование влияния Attention на задачу классификации изображений

## Цель работы

Изучить влияние механизма Attention на качество классификации изображений и сравнить результаты модели с Attention и базовой сверточной нейронной сети.

## Рассматриваемые модели

### Baseline CNN

Базовая модель состоит из двух сверточных блоков:

* Conv2D + ReLU
* MaxPooling
* Conv2D + ReLU
* MaxPooling
* Полносвязный слой

Данная архитектура использует только локальные признаки изображения.

### CNN + Attention

Во второй модели после сверточных слоев был добавлен Attention-блок, вдохновлённый идеями статьи MHLA (Multi-Head Linear Attention).

Архитектура включает:

* Три сверточных блока
* Batch Normalization
* Attention-блок с residual-соединением
* Global Average Pooling
* Полносвязный классификатор

Attention позволяет модели учитывать взаимосвязи между различными областями изображения и формировать более информативные представления объектов.

## Результаты эксперимента

| Модель          | Accuracy | F1-score |
| --------------- | -------: | -------: |
| Baseline CNN    |   0.6638 |   0.6591 |
| CNN + Attention |   0.7400 |   0.7458 |

## Анализ результатов

Полученные результаты показывают, что добавление Attention-механизма позволило заметно улучшить качество классификации.


Также наблюдается рост F1-score с 0.6591 до 0.7458.

Полученные результаты свидетельствуют о том, что модель с Attention лучше учитывает глобальный контекст изображения и способна находить зависимости между удалёнными областями изображения, которые не всегда доступны обычным сверточным слоям.

В данной работе использовалась упрощённая реализация механизма Attention, вдохновлённая идеями статьи MHLA.

Полная архитектура MHLA не воспроизводилась из-за вычислительных ограничений, однако был исследован основной принцип использования Attention для улучшения качества классификации изображений.

Результаты подтверждают, что включение Attention-механизмов может существенно повысить качество модели по сравнению с базовой сверточной архитектурой.

## Вывод

В ходе работы было проведено сравнение базовой сверточной нейронной сети и модели с Attention-механизмом на датасете CIFAR-10.

Эксперимент показал, что добавление Attention улучшило качество классификации:

* Accuracy увеличилась с 66.38% до 74.00%;
* F1-score увеличился с 65.91% до 74.58%.

Таким образом, использование Attention позволяет модели эффективнее анализировать изображение и получать более качественные признаки, что приводит к улучшению итогового качества классификации.
