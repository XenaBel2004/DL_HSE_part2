# Домашнее задание 7. SequenceLab

## Цель работы

Цель работы — изучить механизм для моделирования последовательностей из репозитория SequenceLab и применить похожую идею к задаче классификации.

## Репозиторий

В качестве основы был рассмотрен репозиторий SequenceLab:

https://github.com/LJC-FVNR/SequenceLab

## Задача

В эксперименте использовалась задача Sequential MNIST.

Обычное изображение MNIST размером 28×28 рассматривалось как последовательность из 28 токенов, где каждый токен соответствует одной строке изображения.

Таким образом, задача классификации изображений была сведена к задаче моделирования последовательности.

## Датасет

Использовался датасет MNIST.

Для ускорения эксперимента была взята часть данных:

- train: 12000 объектов;
- test: 3000 объектов.

## Модели

### Baseline MLP

Базовая модель преобразует изображение 28×28 в один вектор длины 784 и подает его в полносвязную нейронную сеть.

Эта модель не учитывает последовательную структуру изображения явно.

### WAVE-like Sequence Model

Вторая модель использует WAVE-like блок, вдохновленный идеями SequenceLab.

Основная идея блока:

- представить изображение как последовательность;
- использовать mixer-блок для смешивания информации по последовательности;
- использовать gate-механизм, который регулирует вклад текущего токена и смешанного контекста;
- применить residual-соединение для более стабильного обучения.

## Результаты

| Model | Accuracy | F1 macro | Training time |
|---|---:|---:|---:|
| Baseline MLP | 0.9380 | 0.9375 | 3.29 sec |
| WAVE-like Sequence Model | 0.9547 | 0.9547 | 13.38 sec |

## Анализ результатов

WAVE-like модель показала более высокое качество по сравнению с базовой MLP.

Accuracy увеличилась с 0.9380 до 0.9547.

F1-score также вырос с 0.9375 до 0.9547.

Это показывает, что учет последовательной структуры изображения помогает модели лучше классифицировать объекты. Baseline MLP рассматривает изображение как один длинный вектор, а WAVE-like модель работает с изображением как с последовательностью строк и может учитывать связи между разными частями изображения.

При этом время обучения WAVE-like модели оказалось больше: 13.38 секунд против 3.29 секунд у baseline. Это ожидаемо, так как sequence-модель имеет более сложную архитектуру.

## Вывод

В ходе работы была рассмотрена идея из репозитория SequenceLab и применена к задаче Sequential MNIST.

Эксперимент показал, что WAVE-like механизм улучшил качество классификации:

- Accuracy выросла с 93.80% до 95.47%;
- F1-score вырос с 93.75% до 95.47%.

Таким образом, использование sequence modeling механизма оказалось полезным для задачи классификации. Модель лучше учитывает структуру входных данных, но требует больше времени на обучение.
